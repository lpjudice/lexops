# Explorações do Setor Fiscal

Esta pasta reúne estudos separados do produto atual para validar a futura experiência do módulo **Setor Fiscal do Escritório**.

Regras desta área:

- não altera rotas, componentes ou estilos do sistema atual;
- não substitui arquivos existentes;
- serve apenas para protótipos, wireframes, textos de produto e ideias visuais;
- pode evoluir para implementação depois da validação.

Arquivos iniciais:

- `fiscal-comparativo-conceitos.md`: direção de UX, arquitetura da tela e variações de visão comparativa;
- `prototipo-dashboard-fiscal.html`: protótipo estático e isolado para inspeção visual local.
